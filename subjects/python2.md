# Python II: Data Life Cycle & Web Scraping

Welcome to **Python II** at Woosong University Kazakhstan — a project-based course focused on the data lifecycle: from environment setup and automated data collection to advanced manipulation, exploratory data analysis (EDA), and baseline machine learning.

This course builds directly on your **Python I** foundation (Core Python & Backend APIs) and bridges the gap between software engineering and practical data science using the industry-standard **Data Stack**.

## Assignments & Kaggle Workflow

- Assignments and labs are delivered through **Kaggle Kernels** and **GitHub**.
- Students will:
  - Set up professional environments using **Anaconda, Virtualenvs, Pip, Jupyter Notebooks, and VS Code**.
  - Fork assignment notebooks, complete data pipelines, and submit final clean CSVs or data visualizations.
  - Automate data collection via **Web Scraping** (`BeautifulSoup4` and `Selenium`/`Playwright`).
  - Follow **PEP8 standards** and write comprehensive Markdown documentation for all Exploratory Data Analysis (EDA) processes.

### ✅ Allowed Tools
- AI tools (ChatGPT, Copilot, etc.) may be used **only for learning, syntax assistance, and debugging**.
- You must fully understand and be able to explain every step of your data cleaning, scraping, and modeling logic.
- **Direct copying of code, scraping scripts, or dataset solutions is strictly prohibited**.

## Course Work & Competitive Data Science

- Throughout the semester, students participate in real-world dataset challenges hosted on **Kaggle**.
- Practice includes timed data-wrangling benchmarks, exploratory data stories, and pipeline building.

## Evaluation Breakdown

| Component | Weight | Description |

## Topics Covered

### 1) Professional Tooling & Core Data Stack

- **Week 1:** Professional Environments (Anaconda, Virtualenvs, Pip, Jupyter Notebooks, VS Code) 
- **Week 2:** High-Performance NumPy (Vectorization, Broadcasting, N-dimensional arrays) 
- **Week 3:** Pandas I (DataFrames, Series, Indexing, loading CSV, SQL, API data) 
- **Week 4:** Pandas II (Data Cleaning: null handling, outliers, merging, pivoting) 
- **Week 5:** Data Visualization (Matplotlib & Seaborn: crafting Data Stories) 

### 2) Baseline ML & Practical Midterm

- **Week 6:** Intro to Scikit-Learn (Feature Scaling, Categorical Encoding, Train/Test Split) 
- **Week 7:** Baseline Machine Learning Models (Linear Regression, K-Nearest Neighbors) 
- **Week 8:** **MIDTERM EXAM (Practical Wrangling Challenge: Transform raw dataset for analysis)** 

### 3) Web Scraping & Applied Data Pipeline

- **Week 9:** Web Scraping I (Parsing static HTML using `BeautifulSoup4`) 
- **Week 10:** Web Scraping II (Dynamic & JS-heavy web automation using `Selenium` / `Playwright`) 
- **Week 11:** EDA & Kaggle Workflow (Exploratory Data Analysis patterns & competition setup) 

### 4) Final Capstone Project Phase

- **Week 12:** Final Project Phase I — **Collection** (Scraping a unique custom dataset) 
- **Week 13:** Final Project Phase II — **Cleaning** (Advanced data wrangling and transformation) 
- **Week 14:** Final Project Phase III — **Modeling** (Applying baseline ML models to the custom dataset) 
- **Week 15:** **FINAL PRESENTATION & DEMO DAY (Presenting the end-to-end pipeline on GitHub/Kaggle)**

## Final Project Requirements

Students will build and present an **end-to-end data pipeline** :
1. **Scrape** a brand new dataset from a real-world web source.
2. **Clean & Structure** the raw data using Pandas.
3. **Analyze & Visualize** key insights (EDA).
4. **Train & Evaluate** a baseline Scikit-Learn model on the dataset.

> _All final projects must be published as a documented **Kaggle Notebook** and backed by a public **GitHub Repository** containing the full codebase and dataset._ 

Consistency is key. Clean your data, ask the right questions, and tell compelling stories with data!
